# Roteiro para NotebookLM — Programação II

## Notebook sugerido

Nome:

`Programação II — Estágio FACSI — Java e OO`

## Fontes principais

Adicionar ao NotebookLM:

1. Formação Programação II — Guia de Estudo
2. Mapa do Código — Conceitos de Programação II
3. UML Final — Decisões de Modelagem
4. Matriz de Auditoria — Sprint 05
5. Regulamentos usados no projeto, apenas quando o estudo envolver regras de domínio
6. Material do professor de Programação II, caso disponível
7. Trechos ou exportação das classes Java principais quando quisermos estudar código

## Regra de uso

O NotebookLM deve ser usado para estudar e recuperar conceitos a partir das fontes.

O VS Code deve ser usado para:
- ler o código real;
- depurar;
- alterar exercícios;
- executar testes;
- observar comportamento.

## Prompt inicial

Use:

```
Quero estudar Programação II usando o projeto Estágio FACSI como caso prático.

Ensine apenas um conceito por vez.

Para cada conceito:
1. explique em linguagem simples;
2. mostre onde ele aparece no projeto;
3. faça uma analogia curta;
4. faça 3 perguntas de compreensão;
5. proponha 1 exercício para executar no VS Code;
6. não avance até eu responder.

Comece por classe, objeto, atributo, método, construtor e instância.
```

## Prompt de revisão

```
Faça uma revisão ativa do módulo que acabei de estudar.

Não entregue as respostas imediatamente.

Faça:
- 5 perguntas conceituais;
- 3 perguntas usando classes reais do projeto;
- 2 pequenos trechos de código para eu prever o resultado.

Depois avalie minhas respostas e explique apenas os erros.
```

## Prompt para preparação oral

```
Atue como professor de Programação II avaliando meu projeto Estágio FACSI.

Faça uma pergunta por vez sobre Java e orientação a objetos.

Priorize:
- classes e objetos;
- encapsulamento;
- herança;
- abstração;
- polimorfismo;
- associações;
- listas;
- enums;
- static;
- testes JUnit.

Depois de cada resposta:
- diga se está correta, parcial ou incorreta;
- corrija de forma breve;
- faça uma pergunta de aprofundamento.
```
