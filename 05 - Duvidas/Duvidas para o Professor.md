# Dúvidas para o Professor

## D-001 — Quantidade de posições

Uma vaga pode disponibilizar várias posições ou cada registro de vaga corresponde exatamente a uma oportunidade?

## D-002 — Supervisor

O supervisor é definido na vaga, no vínculo de estágio ou nos dois momentos?

## D-003 — Troca de supervisor

É possível substituir o supervisor durante um estágio? Caso sim, o sistema deve manter histórico?

## D-004 — Estágio sem candidatura

Pode existir estágio formalizado sem que tenha existido uma candidatura registrada no sistema, por exemplo quando o próprio aluno encontra a oportunidade?

## D-005 — Carga horária simultânea

Qual é exatamente a regra para soma das cargas horárias quando o aluno possui dois ou mais estágios simultâneos?

## D-006 — Orientador

O orientador é escolhido individualmente para cada estágio ou determinado automaticamente de acordo com a modalidade?

## D-007 — Plano de Atividades

O Plano de Atividades pode ser alterado depois de aprovado? Se sim, é necessário manter versões?

## D-008 — Convênio

O convênio habilita a concedente para qualquer curso/campus ou pode possuir restrições específicas?

## D-009 — Encerramento

Quais pendências impedem formalmente o encerramento de um estágio?

## D-010 — Novo estágio com pendências

Um aluno pode iniciar um novo estágio se ainda possuir pendências de encerramento em estágio anterior?
